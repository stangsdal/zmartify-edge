AHC9000 USB Recovery

Geninstaller firmwaren og nulstil gemt Wi-Fi, MQTT og onboarding. Brug kun denne procedure, når controlleren skal flyttes til et andet Wi-Fi eller ikke længere kan forbindes.

Alle lokale konfigurationsdata slettes.

Afbryd controllerens eksterne strømforsyning, før USB tilsluttes. Waveshare-boardet må ikke strømforsynes via terminalblokken og USB samtidigt.

Før du starter

  1. Brug Chrome eller Edge på en computer og et USB-datakabel.
  2. Afbryd controllerens eksterne strøm.
  3. Forbind controllerens USB-C-port direkte til computeren.
  4. Vælg Læs controller-ID, vælg controllerens USB-port, og gem ID'et til onboarding.
  5. Vælg derefter Installer recovery-firmware og den samme USB-port.
Browseren understøtter ikke Web Serial. Brug Chrome eller Edge på en computer. USB-flash kræver, at siden åbnes via HTTPS.
Download factory-image manuelt

Hvis USB-porten ikke vises

Hold BOOT inde, tryk kort på RESET, slip RESET og slip derefter BOOT. Start installationen igen.

Efter installationen

  1. Vent på beskeden om, at installationen er færdig.
  2. Fjern USB-kablet.
  3. Tilslut controllerens normale strømforsyning.
  4. Gennemfør onboarding med ESPTouch V2 og app.zmartify.dk.

Recovery-image: version indlæses.... Normal firmwareopdatering udføres via OTA og nulstiller ikke Wi-Fi.

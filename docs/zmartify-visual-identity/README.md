# Zmartify visual identity package

Version 1.0. The package is designed as a digital-first sibling to CarbEurope.

## Included
- `assets/zmartify-lockup-transparent.png` - transparent lockup extracted from the supplied logo
- `assets/zmartify-app-icon-1024.png` - store master
- iOS / Android app icon sizes: 180, 192, 256, 512, 1024 px
- favicon sizes: 16, 32, 48, 64, 128, 256, 512 px
- `assets/zmartify-pattern-light.png` - repeatable brand pattern
- original supplied logo references
- `zmartify-visual-identity-guide.pdf` - concise usage guide

## Product guidance
Use the symbol without wordmark for app icons and favicon. Use the full lockup for app launch screens, web, store imagery and corporate material. Poppins is the typographic reference; use an approved equivalent if the font is not available in the target platform.

## Note
The supplied logo was delivered as raster artwork. This first package preserves it faithfully and adds scalable usage assets around it. A future designer handoff should replace the transparent lockup with the original vector master if that becomes available.

NILAN USB Recovery

Geninstaller gateway-firmwaren fra USB. En normal opdatering udføres via OTA fra firmwarekataloget.

Recovery kan slette lokal konfiguration. Brug kun installationen som led i service eller genoprettelse.
  1. Brug Chrome eller Edge på en computer.
  2. Forbind ESP32-S3-gatewayen med et USB-datakabel.
  3. Vælg installer og derefter gatewayens USB-port.
Browseren understøtter ikke Web Serial. Brug Chrome eller Edge. USB-installation kræver HTTPS.
